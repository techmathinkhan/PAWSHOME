Chatbot Integration Guide

Set up PawsBot in minutes

🐾 Three Ways to Add PawsBot Choose direct Claude API integration, n8n no-code automation, or a plug-and-play third-party widget.
A Direct Claude API (Recommended)

Add your Anthropic key to app.py and enable the /api/chat endpoint.

1. Get your key: console.anthropic.com

2. Add to app.py:

pip install anthropic import anthropic ANTHROPIC_KEY = "sk-ant-YOUR_KEY_HERE" @app.route('/api/chat', methods=['POST']) def chat(): data = request.json or {} client = anthropic.Anthropic(api_key=ANTHROPIC_KEY) msg = client.messages.create( model="claude-sonnet-4-20250514", max_tokens=300, system="You are PawsBot, adoption assistant for PawsHome.", messages=[{"role":"user","content":data.get("message","")}] ) return jsonify({"reply": msg.content[0].text})

3. In index.html, update sendChat() to call fetch('/api/chat', ...)

B n8n Webhook (No-Code)

n8n forwards messages to Claude and returns replies via a webhook — no code needed.

n8n Workflow: ① Webhook Trigger (POST /webhook/pawsbot) ② HTTP Request → Anthropic API URL: https://api.anthropic.com/v1/messages Header: x-api-key: YOUR_KEY Body: { model, messages, max_tokens } ③ Respond to Webhook → return reply text
⚡ Open n8n.io — Free self-hosted
C Tidio / Crisp (Plug & Play)

Drop one script tag in index.html for a fully-managed AI chat widget.

<!-- Add before </body> --> <script src="//code.tidio.co/YOUR_KEY.js" async></script>
💬 Tidio — Free plan available 💬 Crisp — Free for small teams
💡 Once /api/chat is working, the 🤖 button becomes a live PawsBot chat window. Replace this guide panel with a standard chat UI.
